# UTS Implementasi Kode Deep Learning

Repository ini berisi kumpulan studi kasus dan implementasi kode sederhana sebagai tugas Ujian Tengah Semester (UTS). Setiap sesi mengimplementasikan materi kuliah ke dalam bentuk program menggunakan Python dan Google Colab, dengan studi kasus yang berkaitan dengan permasalahan nyata.

## 📌 Tujuan

- Mengimplementasikan materi perkuliahan ke dalam program sederhana.
- Memahami penerapan analisis data, kecerdasan buatan, dan visualisasi data.
- Menerapkan metode komputasi untuk membantu menyelesaikan permasalahan nyata.
- Mendokumentasikan hasil implementasi setiap sesi dalam satu repository GitHub.

## 📂 Daftar Sesi dan Implementasi

### Sesi 1 – Patterns of Data with Analysis and AI
**Studi kasus:** Analisis Pola Curah Hujan di Bengkulu Utara.

Implementasi ini membahas pengolahan dan analisis data curah hujan untuk mengidentifikasi pola perubahan curah hujan. Analisis dilakukan menggunakan Python untuk membantu memahami karakteristik data dan menyajikan hasilnya dalam bentuk visualisasi.

### Sesi 2 – Bridging Global Infrastructure to Address Local Challenges in High Performance Computing (HPC)
**Studi kasus:** Estimasi Konsentrasi CO Berdasarkan Data Pengamatan.

Implementasi ini membahas pemanfaatan komputasi dan analisis data untuk mengolah data pengamatan serta memperkirakan konsentrasi karbon monoksida (CO). Program menggunakan pendekatan pengolahan data dan pemodelan sederhana sesuai dengan materi sesi.

### Sesi 3 – Career and Competition in Industrial Era with GIS
**Studi kasus:** Pemetaan Daerah Rawan Banjir di Bengkulu.

Implementasi ini menggunakan Geographic Information System (GIS) untuk menampilkan informasi spasial yang berkaitan dengan wilayah rawan banjir. Hasil pemetaan dapat membantu memahami persebaran wilayah yang berpotensi terdampak banjir berdasarkan data yang tersedia.

### Sesi 4 – Introduction to Machine Learning
**Studi kasus:** Klasifikasi Tumor Payudara dengan Machine Learning.

Implementasi ini menerapkan algoritma *machine learning* untuk mengklasifikasikan data tumor payudara ke dalam kategori yang tersedia pada dataset. Tahapan program meliputi persiapan data, pembagian data, pelatihan model, serta evaluasi performa menggunakan metrik klasifikasi.

### Sesi 5 – Human-Computer Interaction & Data Visualization
**Studi kasus:** Perancangan Dasbor Interaktif untuk Analisis Data.

Implementasi ini membahas penyajian data dalam bentuk visualisasi yang informatif dan mudah dipahami. Dasbor dirancang untuk membantu pengguna mengeksplorasi informasi dan memahami pola data melalui tampilan visual yang interaktif.

### Sesi 6 – Pemanfaatan Citra Satelit dan Kecerdasan Buatan untuk Pemantauan Lingkungan
**Studi kasus:** Pemantauan Indikasi Perubahan Tutupan Lahan.

Implementasi ini membahas pemanfaatan citra satelit dan teknik analisis data untuk mengamati indikasi perubahan tutupan lahan. Pendekatan ini dapat mendukung pemantauan lingkungan melalui pengolahan informasi spasial dan perbandingan data yang tersedia.

## 🛠️ Teknologi yang Digunakan

Teknologi yang digunakan disesuaikan dengan kebutuhan masing-masing studi kasus, meliputi:

- **Python** – bahasa pemrograman untuk implementasi.
- **Google Colab** – lingkungan untuk menjalankan kode secara daring.
- **Pandas dan NumPy** – pengolahan dan analisis data.
- **Matplotlib** – visualisasi data.
- **Scikit-learn** – implementasi dan evaluasi model machine learning.
- **Library GIS dan geospasial** – pengolahan serta visualisasi data spasial jika diperlukan.
- **Library pengolahan citra** – analisis citra satelit jika diperlukan.

## 🚀 Cara Menjalankan Program

1. Buka repository ini di GitHub.
2. Pilih file sesuai sesi yang ingin dipelajari.
3. Buka [Google Colab](https://colab.research.google.com/).
4. Unggah file notebook atau salin kode ke notebook Google Colab.
5. Jalankan setiap sel kode secara berurutan.
6. Pastikan dataset dan library yang dibutuhkan tersedia sebelum menjalankan program.

**Catatan:** Nama library, dataset, dan metode yang digunakan dapat berbeda pada setiap sesi. Ikuti petunjuk yang tersedia di dalam kode masing-masing.
